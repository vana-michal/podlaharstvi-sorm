# SectionHeading

Nadpis sekce: `h2` a pod ním volitelně úvod ve stylu `lead`, bez štítku a čísla nad sebou.

- Sekce nejsou postup, proto se nečíslují. Navigaci nese hlavička a samotné nadpisy.
- Mezi nadpisem a úvodem `space-4`, od obsahu sekce `space-12`.
- Úvod max. `text-max` (640 px).
- Ne: štítek nad nadpisem („02 / Služby“), kóta nad nadpisem, zvýraznění jednoho slova v nadpisu.
