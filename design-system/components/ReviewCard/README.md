# ReviewCard

Recenze jako citace bez karet: jedna velká přes celou šířku a dvě menší vedle sebe, každá se jménem zákazníka, pěti hvězdami a plným textem z Googlu.

- Bez rámečku a podkladu; menší citace odděluje od velké linka `line-strong` nad nimi. Sekce má pozadí `surface-sunk`.
- Nahoře jméno jako `<h3>` (17 px, 600), aby čtečka mezi recenzemi skákala po nadpisech, vedle štítek „Recenze na Googlu“ ve stylu `label`.
- Hvězdy ve výplni `accent` s okrovým obrysem `accent-ink`, s `aria-label="5 z 5 hvězd"`.
- Velká citace 24/34 px (na mobilu 20/30), menší ve stylu `body`; text vždy `ink`.
- Text recenze se nezkracuje ani neupravuje. Jména se nemění (přezdívka zůstává přezdívkou). Žádné dopsané titulky: Google recenze je nemají.
- Pořadí: Lucie Valenová (velká), marph81, Petr Čermák. Pod nimi odkazy „Všechny recenze na Googlu“ a „Napsat recenzi“, bez šipek.
- Pod 820 px všechny pod sebou. Další recenze přibývají jako menší citace po dvou.
