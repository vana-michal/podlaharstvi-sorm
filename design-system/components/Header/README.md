# Header

Hlavička: jméno jako slovní značka, navigace na sekce a telefon jako hlavní tlačítko.

- Slovní značka: „Michal Šorm“ v Archivo 750, šířka 112 %, pod ní štítek „Podlahářství od roku 2004“. Logo zatím neexistuje; do té doby je značkou jen sazba jména.
- Navigace: Služby, Reference, Recenze, Kontakt – kotvy na sekce. Hover podtrhne odkaz grafitovou linkou `ink`.
- Telefon: `sp-btn--primary sp-btn--small`, odkaz `tel:`.
- Pod 720 px zmizí navigace a z telefonu zbude ikona s `aria-label`.
- Hlavička se při scrollu může lepit nahoře (`position: sticky`), vždy s dolní linkou `line` a pozadím `surface`.
