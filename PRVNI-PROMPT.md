# Zadání pro Claude Code

Spusť Claude Code v této složce a vlož postupně tyto zprávy. Další pošli až po kontrole výsledku v prohlížeči.

## 1. Kostra stránky

Přečti CLAUDE.md, design-system/README.md a README všech komponent. Pak sestav jednostránkový web v index.html podle sekce „Skladba stránky“: Header, Hero, Služby (SectionHeading, ServiceFloors, ProcessSteps), Reference (BeforeAfter, zatím jedna ukázková zakázka), Recenze (ReviewCard), Kontakt (ContactForm) a patička. Markup a skripty převezmi z preview.html jednotlivých komponent, texty z obsah/texty-webu.md upravené podle pravidel hlasu v design systému. Zkopíruj tokens.css, bundle.css a hairline.js do css/ a js/. Nic neodesílej a nenapojuj. Na konci spusť lokální server a vypiš všechny zástupné údaje, které je potřeba ověřit.

## 2. Kontrola

Projdi stránku na šířce 375 px a 1280 px, v obou barevných motivech, z klávesnice a s prefers-reduced-motion. Oprav, co nesedí s design systémem, a vypiš, co jsi změnil.

## 3. Doplňky

Doplň SEO z obsah/texty-webu.md (title, meta description, Open Graph, strukturovaná data LocalBusiness s telefonem a oblastí působnosti), favicon ze slovní značky a stránku zasady-ochrany-osobnich-udaju.html se zástupným textem označeným k doplnění.

## 4. Formulář a nasazení (až budou rozhodnutí)

Napoj formulář na [doplnit službu, např. Formspree nebo PHP skript na hostingu], přidej skryté pole proti spamu a připrav nasazení na [doplnit hosting].
